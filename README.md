# Calendrier édito WebGen

Page publiée sur https://elie2312.github.io/calendrier-edito/ : le calendrier éditorial des reels WebGen, **chiffré** (staticrypt).
Le contenu n'est lisible qu'avec le mot de passe.

Généré et poussé automatiquement par Hermes (`~/.hermes/scripts/calendar-publish.sh`, toutes les 10 min si le calendrier a changé)
depuis `hermes/calendar/index.html`. Ne pas éditer à la main.
